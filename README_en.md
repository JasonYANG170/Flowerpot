## Features
- ✅ Anthropomorphic expressions
- ✅ ChatGPT text interaction model
- ✅ OpenCV deep visual recognition algorithm
- ✅ Client remote control Android/Windows
- ✅ Soil warming
- ✅ Wireless charging
- ✅ Battery charging
- ✅Battery level display
- ✅ Support mqtt server sending and receiving
- ✅Support OTA technology
- ✅ Support webserver local server
- ✅ Passive soil humidification

## system
#### FlowerpotOS2.0
Developed based on the Arduino platform, mainly using third-party libraries to implement functions

#### FlowerpotOS3.1
Developed based on the PlatformIO platform, third-party libraries were eliminated and developed by ourselves.
Greatly reduce the program space occupied and eliminate redundant functions and third-party libraries
Supports FS file system and WebServer service developed based on Bootstorp5
